# Narration Audio File Map — Pequenos Traços de Fé

Lista completa dos 200 arquivos de áudio esperados, na ordem de gravação.

**Padrão:** `audio_{storyId}_scene_{NN}.mp3`  
**Destino no app:** `assets/audio/{storyId}/audio_{storyId}_scene_{NN}.mp3`

> Atenção: o nome do arquivo no app usa a convenção `{storyId}_scene_{NN}.mp3`.
> O prefixo `audio_` é apenas para identificação na lista de gravação.
> Ao mover para o app, use o nome sem o prefixo `audio_`.
