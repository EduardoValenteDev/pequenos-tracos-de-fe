## Instruções de gravação

### O que narrar

Narrar **exatamente** o campo **"Texto para narrar"** de cada cena no roteiro.

Não narrar:
- O título da cena
- O número da cena
- A referência bíblica
- A direção de voz (ex: "Voz tranquila e reverente")
- A sonoplastia (ex: "Chuva leve ao fundo")

### Um arquivo MP3 por cena

Cada cena gera um arquivo MP3 separado. Não juntar cenas no mesmo arquivo.

### Nomenclatura obrigatória dos arquivos

```
{storyId}_scene_NN.mp3
```

Exemplos corretos:
```
creation_scene_01.mp3
noah_scene_01.mp3
david_goliath_scene_01.mp3
jesus_children_scene_05.mp3
```

**Não usar** o prefixo `audio_`. O arquivo deve ir direto para a pasta `assets/audio/{storyId}/` no app.

### Não alterar o texto

Narrar as palavras exatamente como estão escritas. Não substituir, resumir, improvisar ou acrescentar palavras.

### Falas de personagens bíblicos

Algumas cenas contêm falas diretas (entre aspas) atribuídas a personagens bíblicos. Narrar essas falas com o mesmo respeito do restante do texto — **sem voz caricata, sem dramatização exagerada**.

### Em caso de dúvida

Se houver qualquer dúvida sobre pronúncia de nome bíblico, sobre uma frase do texto ou sobre a intenção editorial:

**Pausar a gravação e perguntar** antes de improvisar.
